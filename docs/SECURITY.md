# سياسة الأمان والخصوصية — SECURITY & DATA INTEGRITY
**نظام ميزان المحاسبي الشامل — MIZAN ACCOUNTING ULTRA**

---

## 1. حماية البيانات المالية والخصوصية المطلقة (Privacy-First)
- التطبيق يعمل بنمط **Offline-First** بنسبة 100%.
- لا يتم إرسال أي أرقام فواتير أو أرصدة أو أسماء عملاء إلى خوادم خارجية أو أطراف ثالثة.
- جميع العمليات الحسابية والرسومية ثلاثية الأبعاد ومعالجة الصور تتم محلياً على جهاز المستخدم داخل المتصفح.

## 2. مناعة القيود من التلاعب والتكرار
- **Idempotency Guard**: منع تكرار ترحيل الفاتورة الواحدة عند النقر المزدوج على زر الحفظ.
- **Ledger Verification**: فحص توازن المدين والدائن قبل الحفظ، مع رفض أي قيد غير متوازن على الفور.
- **Backup Checksum**: عند تصدير النسخة الاحتياطية، يتم حساب رمز تجزئة (Checksum) ويتم التحقق من سلامة البنية وتوازن القيود بالكامل قبل قبول استيراد أي ملف احتياطي.

## 3. صلاحيات الكاميرا والماسح الذكي
- يتم طلب إذن الكاميرا فقط عند فتح شاشة "الماسح والباركود" أو استخدام مسح الباركود، مع توفير بديل يدوي بالكامل في حال رفض الإذن أو عدم توفر كاميرا.
- لا يتم حفظ أو رفع صور الكاميرا خارج الذاكرة المؤقتة للمتصفح.
